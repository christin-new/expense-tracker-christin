# Expense Tracker

A simple and responsive web-based **Expense Tracker** built using HTML, CSS, and JavaScript.

## Features

* Add income and expense transactions
* Enter amount, category, date, and description
* Calculate total income
* Calculate total expenses
* Display current balance
* Edit transactions
* Delete transactions
* Filter transactions by type or category
* Responsive design for desktop and mobile devices

## Technologies Used

* **HTML** – Structure of the application
* **CSS** – Styling and responsive design
* **JavaScript** – Application functionality and calculations

## Project Structure

Expense-Tracker/
│
├── index.html
├── style.css

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a browser or VS Code Live Server.
4. Add income or expense transactions.
5. Use the Edit, Delete, and Filter options to manage transactions.
